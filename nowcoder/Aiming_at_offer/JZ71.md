# JZ71.跳台阶扩展

```cpp
class Solution {
public:
    // F(0) = 1
    // F(1) = F(0) = 1
    // F(2) = F(0) + F(1) = 2
    // F(3) = F(0) + F(1) + F(2) = 4
    // F(4) = F(0) + F(1) + F(2) + F(3) = 8
    // F(5) = F(0) + ... + F(4) = 16
    int jumpFloorII(int number) {
        int ans = 2;
        return std::pow(ans, number - 1);
    }
};
```
