# JZ69.跳台阶

```cpp
class Solution {
public:
    int jumpFloor(int number) {
        int left = 1, right = 1;
        if(number == 1) return right;
        int ans = 0;
        for(int now = 2; now <= number; now ++){
            ans = left + right;
            left = right;
            right = ans;
        }
        return ans;
    }
};
```
